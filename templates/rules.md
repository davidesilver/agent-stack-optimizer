# Agent workflow

- Keep one task per session; save a concise handoff at a logical stopping point.
- Read indexes first and retrieve only the files relevant to the task.
- Prefer deterministic scripts for repeated operations and CLI tools where practical.
- Extract text from text-based PDFs; use the original when images or layout matter.
- Keep responses concise. Preserve error details and access to original tool output.
- Do not change the model or reasoning effort automatically.
- Use the configured context warning/handoff thresholds; they are preferences, not claims about pricing or quality.
